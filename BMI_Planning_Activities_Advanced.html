The project tracker

Info Card: read this first

What is it?

A project tracker lists every task in a project, when it will be done, who does it and its status (done, in progress, not started). It helps a team manage its time and see what is left.

The 5 stages of the Systems Development Lifecycle (SDLC)

  1. Project brief: read what the program must do (the requirements).
  2. Planning: decompose the problem, draw a flowchart, write pseudocode.
  3. Programming: write the real code.
  4. Testing: try the program with test values and fix errors.
  5. Self-reflection: decide what went well and what to improve.

Example: tracker for a temperature converter project

Tips

  • Give each stage a realistic amount of time. Testing usually takes longer than people expect.
  • Update the status at the end of every lesson.
  • Give every task an owner so nothing is forgotten.

Decomposition

Info Card: read this first

What is it?

Decomposition means breaking a big problem into smaller parts that are easier to understand, build and test. Programmers often split a program into three parts:

  • Input: the data that goes into the program (what the user types).
  • Process: what the program does with the data (calculations and decisions).
  • Output: the result the program shows.

Program example: temperature converter (°C → °F)

INPUT

Ask for the temperature in °C.

Cast it to a decimal (float), because input is text.

PROCESS

Calculate F = C × 9 ÷ 5 + 32

Decide: is C 30 or more? Then it is hot.

OUTPUT

Print the temperature in °F.

Print “It is hot!” or “It is not hot.”

Flowcharts

Info Card: read this first

What is it?

A flowchart is a diagram of an algorithm. Each step goes in a symbol and arrows show the order of the steps.

TerminatorStart or Stop
Input / OutputINPUT data or PRINT a result
ProcessA calculation or action
DecisionA Yes / No question with two exits

Rules

  • One Start and one Stop.
  • Arrows usually go from top to bottom.
  • Every decision has two arrows, labelled Yes and No.

Station D · Activity 8

Pseudocode

Info Card: read this first

What is it?

Pseudocode writes the steps of a program in simple, code-like English. It is not a real programming language, but it must be clear and in the right order.

Keywords

  • INPUT: get data from the user
  • PRINT: show a result
  • IF … THEN: make a decision
  • ELSE: what happens otherwise
  • END IF: close the decision

Rules

  • Write keywords in CAPITALS.
  • One step on each line.
  • Indent the lines inside an IF.
  • Each line matches one box in the flowchart.

Example: temperature converter

START
INPUT celsius
celsius = FLOAT(celsius)
f = celsius * 9 / 5 + 32
PRINT f
IF celsius >= 30 THEN
    PRINT "It is hot!"
ELSE
    PRINT "It is not hot."
END IF
STOP
